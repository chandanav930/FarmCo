# Farm Co. Website

A responsive static website for Farm Co., built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Publish free with GitHub Pages
1. Open your GitHub repository.
2. Click **Add file → Upload files**.
3. Upload `index.html` (and this README if you like) from this folder.
4. Click **Commit changes**.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose branch **main** and folder **/(root)**, then click **Save**.
8. Wait a few minutes. GitHub will show your website URL in the Pages section.

## Important before launch
- The farm cards are sample/demo listings. Replace their names, locations, photos and prices with verified farm partners and real details.
- Booking and contact forms currently open the visitor's email app using `mailto:`. They do not store submissions or confirm bookings. For real online bookings, connect a backend or form service and add availability, payment, cancellation and safety workflows.
- Photos and fonts load from Unsplash and Google Fonts, so an internet connection is needed for those assets.
- Update the contact email in `index.html` if it changes.
