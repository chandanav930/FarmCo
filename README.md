# Farm Co. — interactive website starter

A responsive Next.js website for Farm Co. with farm discovery, category filters, search, experience detail popups, booking/partnership enquiry forms, responsive navigation and newsletter interaction.

## Run locally
1. Install Node.js 20 or later.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Deploy
This project is configured for a static export (`out/`) and can be deployed to Vercel or GitHub Pages. For Vercel, import the repository and use the default Next.js build settings. For GitHub Pages, configure the deployment workflow to publish the `out` directory.

## Important before launch
- The enquiry form currently demonstrates client-side validation and confirmation only. Connect it to a database/API or form service before accepting real bookings.
- Farm listings and prices are sample content. Replace them with verified farm partners, availability, safety details and accurate prices.
- Add a privacy policy, terms, cancellation policy and contact details.
- External photos and Google Fonts require an internet connection.
